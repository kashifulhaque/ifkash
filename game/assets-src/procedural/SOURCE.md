# Procedural models

- **Author:** The Cinderheart project
- **License:** Original work of this repository. See `LICENSE.md` in this folder.
- **Source:** `build.mjs` in this folder, built with `@gltf-transform/core`. Rebuild with `bun game/assets-src/procedural/build.mjs`; the output is deterministic.
- **Status:** `lantern.glb` is committed and draws the Lantern in one test area, Hollowhearth. The other 17 models that `build.mjs` writes are staged on the branch `claude/game-models-staging-b685dc` and aren't committed here. See [MODELS.md](../../../docs/game/assets/MODELS.md#model-files-in-the-engine).

These are the props and landmarks that no CC0 pack covers: the Lantern, the Warden Brazier, the Glasswing mirror, Hollowdeep's crystals, glowing fungi, and the Lamp Tree, the mine rails and cart, the lever, the ladder, the reed clump, the Spire's woven pieces, the Great Bell, and the aqueduct bays.
