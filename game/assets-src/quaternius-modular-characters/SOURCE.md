# Quaternius modular characters

- **Source:** The Modular Men pack and Modular Women pack by Quaternius, https://quaternius.com. These files were already in the repo at `static/models/npc/` (see `static/models/CREDITS.md`); `Adventurer.glb` was copied here as the Wayfarer source. It was not downloaded again.
- **License:** CC0 1.0 Universal (https://creativecommons.org/publicdomain/zero/1.0/). The pack ships no license file in this repo; the license is as stated on the author's pack pages and in `static/models/CREDITS.md`. No attribution is required.
- **Rig:** Mixamo-style names with `.L` and `.R` suffixes (`Hips`, `Abdomen`, `Torso`, `Chest`, `UpperLeg.L`, and so on), 49 bones. Materials use flat colors, no textures.
